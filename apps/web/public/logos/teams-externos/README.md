# Logos de times externos (adversários)

Coloque aqui os logos dos times que **não** são o time da página (visitantes ou adversários quando jogamos fora).

**Nome do arquivo:** use o nome do time em minúsculas, com hífens no lugar de espaços e sem acentos.

Exemplos:

- `sao-paulo-fc.png`
- `corinthians.png`
- `palmeiras.webp`

Formatos aceitos: `.png`, `.webp` ou `.svg`. O componente tenta carregar nessa ordem; se não encontrar, exibe um ícone padrão.
